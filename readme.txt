AETHER - راهنمای اجرا
1- سایت: فایل AETHER.html را دوبار کلیک کن تا در مرورگر باز شود. بدون فیلتر تست کن.
2- ربات بله: اول پایتون 3.10 به بالا نصب کن.
بعد این دستور را بزن:
pip install requests jdatetime
بعد اجرا:
python aetherbot.py
تا روشن است ربات جواب میدهد. برای همیشه روشن ماندن روی سیستم یا سرور بگذار.
3- دستورات مدیر در بله:
/stats - آمار کاربرها
/reply آیدی متن - جواب به کاربر
/all متن - پیام همگانی
4- همه نظرهای سایت و ربات فقط برای مدیر می آید.
