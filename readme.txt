AETHER - راهنمای اجرا بدون گیت‌هاب
1- سایت:
فایل AETHER.html را دوبار کلیک کن تا در مرورگر باز شود.
بدون فیلترشکن تست کن تا قسمت نظرات کار کند.
توکن جدید داخل فایل گذاشته شده و لازم نیست چیزی را عوض کنی.

2- ربات بله:
اول پایتون 3.10 به بالا نصب کن.
بعد این دستور را بزن:
pip install requests jdatetime
بعد اجرا:
python aetherbot.py
تا روشن است ربات جواب می‌دهد. برای همیشه روشن ماندن روی سیستم یا سرور بگذار.

3- دستورات مدیر در بله:
/stats - آمار کاربرها
/reply آیدی متن - جواب به کاربر
مثال: /reply 123456 سلام ممنون
/all متن - پیام همگانی به همه کاربرها

4- همه نظرهای سایت و ربات فقط برای مدیر می‌آید.
آیدی مدیر: 1245087906
فایل users.json خودش ساخته می‌شود و لازم نیست بسازی.
